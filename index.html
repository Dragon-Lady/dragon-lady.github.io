Recent tool releases

Here are the tools Dragon Lady has released on PyPI lately, with each tool's current version and what it does. Names, versions and dates come from each tool's PyPI page (dates in UTC).

Push Guard

push-guard 0.4.3, released October 20, 2026
PyPI · Source

A Git pre-push check. It scans what you are about to push, flags likely secrets and private file paths with the matched values hidden, and stops the push so credentials stay off GitHub.

Upgrade note: 0.4.3 removes the inline # push-guard: ignore exception.

Actions Warden

actions-warden 0.1.5, released October 16, 2026
PyPI · Source

A read-only auditor for GitHub Actions workflows. It scans workflow files for risky or injected configuration and reports alerts.

Prompt Injection Blocker

prompt-injection-blocker 0.1.7, released October 16, 2026
PyPI · Source

A read-only scanner that finds prompt-injection text in files, built to run before an assistant reviews them.

Game Mod Guard

game-mod-guard 0.1.4, released October 16, 2026
PyPI · Source

A read-only checker for downloaded game mods and mod archives. It flags executables hiding in archives, scripts, and nested archives before you install.

Net Ward

netward 0.4.12, released October 23, 2026
PyPI · Source

"A user-space deception layer that turns DDoS and bot abuse into wasted effort." It runs as a reverse proxy in front of an HTTP service.

Twin Update

twin-update 0.4.1, released October 25, 2026
PyPI · Source

Closes, updates and verifies the same apt-packaged desktop apps on two Linux machines in one run, with a verified one-command rollback. Built for Debian and Ubuntu-family desktops.
